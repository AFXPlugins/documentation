Changelog

Notable changes to CustomAdvancementMessages, newest first.

1.0.1
  • New: Support for more versions
  • New: built-in {player} placeholder for player-name-format, resolving to the player's username regardless of PlaceholderAPI. It's now the default value.
  • New: Config migrator
  • New: separate customadvancementmessages.updatenotify permission controls who gets the join-time update notice, independent of .admin.
  • Changed: PlaceholderAPI is now a required dependency. The plugin no longer falls back to plain usernames when it's missing and it won't enable at all without it.
1.0.0
  • New: initial release.
