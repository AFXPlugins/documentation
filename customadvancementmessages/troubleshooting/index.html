Troubleshooting

Common issues and how to fix them.

Plugin won't enable

Check your console for a message about a missing dependency. PacketEvents is a required dependency — if it isn't installed and enabled, CustomAdvancementMessages won't start.

Player names show as plain usernames instead of placeholders

Check your console on startup for PlaceholderAPI not found. Placeholder support disabled. If you see that line, install PlaceholderAPI. Also make sure to install any expansions the placeholder needs (e.g., the LuckPerms expansion for %luckperms_prefix%). You can confirm a placeholder resolves correctly on its own with /papi parse <username> <placeholder> in-game.

Advancement messages aren't being rewritten at all

  • Confirm PacketEvents is actually enabled (not just installed) — check its own console output on startup.
  • Try /advancements preview to test if that works properly.
Still stuck?

Submit an issue on the CustomAdvancementMessages GitHub repository and include details about the problem and how to reproduce it.
